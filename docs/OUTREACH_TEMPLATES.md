# MigrationProof outreach — templates for manual review and sending

I'm speaking with Microsoft data migration teams about how they verify schema, row counts and business-critical totals before signing off a cutover.

## 5-minute demo sequence

1. Show two **synthetic** source/target databases with equal row counts.
2. Show a deliberate change to a numeric value in the target.
3. Independently collect both snapshots using approved read-only access.
4. Generate a discrepancy report and explain precisely what was checked.
5. Explain what is **not** checked, then ask how the prospect currently signs off migration acceptance.

Do not send unsolicited bulk mail, imply independent certification, or claim customers/results not yet earned.
